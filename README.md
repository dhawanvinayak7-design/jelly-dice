# Jelly dice

Squishy jelly dice you can poke, pull, and roll. Pick a flavor, change the count, and watch them wobble.

Single static file: `index.html`. Three.js is loaded from cdnjs, fonts from Google Fonts. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Deploy

- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Vercel:** import the repo. Vercel Analytics only records data on Vercel deployments.
